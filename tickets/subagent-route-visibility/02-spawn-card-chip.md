# Тикет 2 — Чип маршрута в карточке спавна субагента

Блокеры: нет (пакеты не пересекаются с тикетом 1; может идти параллельно в отдельном worktree).

## Зачем

Карточка спавна показывает явный выбор маршрута только в раскрытых аргументах, а унаследованный маршрут не виден вовсе. Чип в свёрнутой шапке делает записанный выбор модели видимым без раскрытия — макет 3, принятый оператором; name-tag макета в v1 не входит (решение D2).

## Что делает

В [details-row.tsx](../../packages/client/ui-tool/src/client/tool/toolviews/details-row.tsx) (`DetailsRow`) свёрнутая шапка карточек `subagent`/`subagent_fork` получает чип маршрута между локализованным заголовком и правой капсулой времени/disclosure. Данные: `meta.name ?? args.name` → ряд `subagentCatalog` родителя через `useSessions` (framework standing seat) → `summaries[childId].projectionValues.modelSelection` (`next ?? lastUsed`). До первого запроса ребёнка — чип из явных аргументов `provider/model/reasoning_effort` только когда прочитаны оба `provider` и `model` (частичные аргументы стримящегося вызова → чип скрыт); отсутствующее усилие → «default»; аргументов маршрута у `subagent_fork` в shipped-пресетах нет → чип появляется с проекцией. Fork-карточка: унаследованный маршрут с создания. Исторические ряды без имени и external-исполнения чипа не получают; аннотации наследования нет; легенды макетов неконтрактны. Output-схема инструмента и `presentationMeta` не меняются — канал чисто клиентский. Ключи чипа — во всех 8 словарях `conversation` NS [ui-conversation locales.ts](../../packages/client/ui-conversation/src/client/locales.ts) (ui-tool своих продуктовых словарей не владеет); подпись «default» согласована с каталогом. Фикстура `subagent-conversation` ([subagent-conversation.e2e.ts](../../apps/web/tests/subagent-conversation.e2e.ts)) расширяется записанным вызовом `subagent` с producer-meta `{kind, name:'agent-1'}` под существующий ряд каталога — assembled-носитель чипа (D1). README ui-tool и JSDoc `DetailsRow` обновляются в этом же тикете. Спека: [subagent-route-visibility.md](../../docs/plans/subagent-route-visibility.md), п.2 «Готово».

## Демо-путь

Keyless scaffold, расширенный сценарий `subagent-conversation`: карточка спавна добавленного вызова показывает чип маршрута в шапке без раскрытия; ряд каталога `agent-1` несёт тот же маршрут. Охранники `subagent-summary` и `tool-details` (карточки без имени) чипа не показывают. Проба в обеих темах; скриншоты читает исполнитель. Replay-голдены краснеют до тикета 3 — ожидаемо.

## Критерии приёмки (падают на базовом коммите)

1. Компонентная спека: карточка с `meta.name`, резолвящимся в ряд каталога, и `modelSelection` ребёнка в summary рендерит чип маршрута в свёрнутой шапке между заголовком и капсулой времени; name-tag отсутствует. Артефакт: вывод `pnpm run test:gui` по новой спеке; ожидание: спека п.2 «Готово». На базовом дереве чипа нет — спека падает.
2. Компонентная спека парных состояний: явные аргументы с прочитанными `provider`+`model` дают чип (effort verbatim либо «default»); частичные аргументы (`provider` без `model`) → чип скрыт; ряд без имени и external → чипа нет; fork с унаследованным маршрутом → чип с создания. Артефакт: вывод test:gui; ожидание: спека п.2 (фолбэк, частичные аргументы, скрытые состояния, fork). Положительная ветка падает на базовом дереве; скрытые ветки — охранники.
3. Assembled-носитель: расширенный `subagent-conversation` содержит записанный вызов `subagent` с producer-meta `{kind, name:'agent-1'}`; ассерт «чип виден в шапке карточки без раскрытия» проходит на дереве тикета. Артефакт: вывод keyless e2e сценария и дифф голдена шапки; ожидание: спека п.2 и решение D1; пустой diff чип-носителя = падение. На базовом src чип не рендерится — ассерт падает.
4. Охранники и гейты: голдены `subagent-summary` и `tool-details` не меняются (карточки без имени → чипа нет); существующие спеки ui-tool/ui-conversation зелёные; полнота 8 словарей `conversation` — `build:check`; `verify-client-ui-i18n` без захардкоженной копии; `pnpm run test:gui` без новых падений относительно базового списка; lint/oxlint по ui-tool/ui-conversation; per-file coverage 100% на тронутом src. Артефакт: выводы команд и пустой дифф охранников; ожидание: спека п.2–4 «Готово».
5. Документация: README ui-tool и JSDoc `DetailsRow` описывают чип карточки. Артефакт: вывод `pnpm run test:docs` без новых падений; ожидание: спека п.5 «Готово».
