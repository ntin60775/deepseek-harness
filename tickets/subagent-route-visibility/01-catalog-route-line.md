# Тикет 1 — Строка маршрута в каталоге субагентов

Блокеры: нет.

## Зачем

Каталог субагентов показывает описание, имя, статус, токены и время, но не показывает, на каком провайдере/модели и с каким reasoning effort работает ребёнок; унаследованный маршрут не виден вовсе. Строка маршрута в каждом ряду делает записанный выбор модели видимым без раскрытия — главный рычаг юнита, принятый оператором как макет 1.

## Что делает

В [SubagentHeaderLineage.tsx](../../packages/client/ui-subagent/src/client/SubagentHeaderLineage.tsx) (`CatalogRows`) каждый локальный ряд получает третью строку под именем: маршрут `provider/model` код-токеном verbatim, 11px/16px приглушёнными чернилами темы, рядом чип effort 10px на приподнятой заливке темы с радиусом `--dsw-radius-xs`. Строка выравнивается по колонке имени (наследует отступ ряда, включая disclosure-колонку) и живёт внутри `.clickarea` — hover/focus-заливка ряда накрывает её; чип effort не сжимается, маршрут уходит в ellipsis. Значение — `modelSelection` дочерней сессии (`next ?? lastUsed`) из `summaries[entry.id].projectionValues` тем же каналом, что `tokenUsage`/`subagentTiming`, без fallback на живые AgentOptions; pending-переключение у адресованного ребёнка недостижимо и отдельного носителя не требует. Effort отсутствует → локализованный чип «default» («явного выбора не было, решает адаптер»); id effort — verbatim. Скрытые состояния: projection-значение пусто (ребёнок до первого `request/header`; маршрут из дескриптора в v1 не показывается), external, unknown (граница объёма), migration-required (сигнал `formatStatus`/состояние дочернего каталога). Fork-ребёнок: унаследованный `lastUsed` показывается с создания без аннотации. Длинный маршрут — ellipsis + Tooltip с полным маршрутом, на touch — tap-to-show через существующий `openOnClick`; полный маршрут и строка маршрута входят в `aria-label` ряда. Формула ширины меню `min(360px, 100vw − 32px)`, перенос описания, колонка метрик, disclosure-геометрия и коннекторы ветвей не меняются; ряд растёт только по высоте на строку маршрута. Новые ключи — во всех 8 словарях [ui-subagent locales.ts](../../packages/client/ui-subagent/src/client/locales.ts). README ui-subagent и JSDoc `CatalogRows` обновляются в этом же тикете. Спека: [subagent-route-visibility.md](../../docs/plans/subagent-route-visibility.md), п.1 «Готово».

## Демо-путь

Keyless scaffold, сценарий `subagent-conversation` (`launchWebScaffold`, chromium установлен): открытый каталог показывает строку маршрута с чипом «default» у живого `agent-1`, у записанных one-shot/grandchild строка скрыта. Проба в обеих темах, на узкой ширине (viewport < 392px, ряд уровня 2) и touch; скриншоты читает исполнитель. Replay-голдены каталога краснеют до тикета 3 — ожидаемо, refresh отдельным блокирующим тикетом.

## Критерии приёмки (падают на базовом коммите)

1. Компонентная спека: локальный ряд с `modelSelection` ребёнка в summary рендерит третью строку с verbatim `provider/model` и чипом effort; строка внутри `.clickarea`, выровнена по колонке имени. Артефакт: вывод `pnpm run test:gui` по новой спеке; ожидание: спека п.1 «Готово». На базовом дереве строки нет — спека падает.
2. Компонентная спека: effort отсутствует → локализованный чип «default»; заданный id effort рендерится verbatim. Артефакт: вывод test:gui; ожидание: спека п.1 и решение гейта о чипе «default». На базовом дереве чипа нет — спека падает.
3. Компонентная спека парных состояний: ряд с записанным маршрутом показывает строку, ряды без маршрута (пустая проекция, external, unknown, migration-required по `formatStatus`) — не показывают; fork-ребёнок с унаследованным `lastUsed` показывает строку с создания. Артефакт: вывод test:gui; ожидание: спека п.1 (скрытые состояния, fork). Положительная ветка падает на базовом дереве; скрытые ветки — охранники.
4. Компонентная спека: `aria-label` ряда содержит маршрут и effort; Tooltip с полным маршрутом присутствует и поддерживает tap-to-show (`openOnClick`). Артефакт: вывод test:gui; ожидание: спека п.1 (aria, touch). На базовом дереве маршрут в имени отсутствует — спека падает.
5. Живая проба: строка и чип видны у `agent-1`, скрыты у записанных детей; контраст 11px-строки и чипа читаем в обеих темах; на узкой ширине и ряду уровня 2 чип не сжимается, маршрут в ellipsis; на touch полный маршрут доступен tap-to-show. Артефакт: прочитанные скриншоты пробы; ожидание: спека п.1 и «Ограничения». На базовом дереве строки нет — критерий не выполняется.
6. Охранники и гейты: существующие спеки ui-subagent зелёные; полнота 8 словарей — `build:check`; `verify-client-ui-i18n` без захардкоженной копии; `pnpm run test:gui` без новых падений относительно базового списка (docs/ops/continue.md); lint/oxlint по ui-subagent; per-file coverage 100% на тронутом src. Артефакт: выводы команд; ожидание: спека п.3–4 «Готово».
7. Документация: README ui-subagent и JSDoc `CatalogRows` описывают строку маршрута. Артефакт: вывод `pnpm run test:docs` без новых падений; ожидание: спека п.5 «Готово».
