# Тикет 5 — Карточки всех реплик и синяя полоса финала

Блокеры: нет (тикеты 1–3 слиты в master).

## Зачем

Решение оператора 2026-11-12 (приёмка макета `.scratch/transcript-cards/`): избирательный карточный вывод режет глаз — карточку должна получать каждая реплика агента; подпись «Окончательный ответ» — лишний текст, финал отличает цвет. Принятый вариант: синий, полоса слева. Макет использует токены GUI один в один; правка живёт в ui-chat поверх слитого тикета 2.

## Что делает

- Каждая Assistant-реплика response-места (`groupPart !== 'reasoning'`, включая неgrouped-рендер) получает приподнятую карточку: `--dsw-specific-input-major`, `--dsw-radius-xl`, `border: 0`, `--dsw-elevation-panel`, padding `14px 16px 16px`. Карточка не зависит от состояния хода и режима: streaming, settled, interrupted, image-only. Reasoning-место карточки не получает.
- Финал (предикат без изменений: `turn.status === 'closed'`, `turn-tail.closing.finalNode.seq === data.finalNode.seq`, response-место, `turn/end.reason === 'completed'`) дополнительно получает левую полосу: `border-left: 3.5px solid var(--dsw-alias-state-business-primary)` (deepseek-500 светлая / deepseek-400 тёмная); `padding-left: 12.5px` компенсирует полосу, чтобы ось текста карточек совпадала. Полоса — модификатор карточки: без карточки полосы нет. Подписи нет.
- Ключ `message.finalAnswer` удалён из всех 8 словарей; `.finalAnswerLabel` и рендер подписи удалены. `data-final-answer` сохранён как маркер полосы; добавлен `data-reply-card` как маркер карточки.
- Пузырь пользователя, контейнер процесса, сворачивание и таблица режимов не меняются.

## Демо-путь

Собрать бандл ui-chat (`pnpm --filter @deepseek-ai/dsh-client-ui-chat bundle`) или держать `pnpm run dev:web`, обновить GUI. Живая сессия: все реплики агента в карточках одного материала, финал завершённого хода — с синей полосой слева и без подписи; то же в Verbose и при свёрнутом процессе. Повторить в светлой и тёмной темах и на узкой ширине.

## Критерии приёмки (падают на базовом коммите)

1. Спека карточек: каждая response-реплика (промежуточная, streaming, image-only) несёт `data-reply-card`; reasoning-место — без карточки и без полосы. Артефакт: вывод focused-прогона ui-chat; ожидание: спека п.2. На базовом дереве карточка только у финала — спека падает.
2. Спека полосы: предикат финала без изменений; полоса только на финале; подписи нет ни в одной из 8 локалей. Артефакт: вывод focused-прогона ui-chat; ожидание: спека п.2. На базовом дереве подпись рендерится — спека падает.
3. Спека материала: `.card` — приподнятая семья; `.finalAnswer` — `border-left: 3.5px solid var(--dsw-alias-state-business-primary)` + `padding-left: 12.5px`. Артефакт: вывод focused-прогона ui-chat; ожидание: спека п.2. На базовом дереве правил нет — спека падает.
4. Locale: ключ `message.finalAnswer` отсутствует во всех 8 словарях, locale-parity зелёный. Артефакт: вывод focused-прогона и locale-dictionaries; ожидание: спека п.2.
5. Живая проба: полоса читается на карточке в обеих темах, ось текста карточек совпадает. Артефакт: снимки пробы; ожидание: спека п.5.
6. Документация: README ui-chat (en+zh пара), JSDoc AssistantMarkdown/AssistantNodeView обновлены. Артефакт: вывод `pnpm run test:docs`; ожидание: спека п.6.
