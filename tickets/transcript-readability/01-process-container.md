# Тикет 1 — Контейнер группы процесса

Блокеры: нет.

## Зачем

Видимое тело группы процесса (строки инструментов, команд, reasoning) сливается с репликами агента в одну стену. Контейнер отделяет машинную работу как блок работы, оставляя речь на чистом фоне — главный рычаг иерархии, перенесённый из omp на единицу DSH-группы.

## Что делает

Оборачивает видимое тело группы в [ChatGroupSeat.tsx](../../packages/client/ui-chat/src/client/chat/ChatGroupSeat.tsx) в тихую оболочку: фон `--dsw-alias-markdown-code-block`, hairline 0.5px `--dsw-alias-border-l1`, радиус `--dsw-radius-lg`. Оболочка — всегда смонтированный presentational div внутри `div[data-chat-group-key]` вокруг тела, вне `[data-step-process-content]`, без роли/aria-label и без overflow/contain/transform; тело остаётся единственным scrollport, fade-маски на теле. Переключение раскрытия меняет только материал классом: участники не перемонтируются, disclosure-состояния и якоря позиции сохраняются, высота строки заголовка не скачет под fold-часами; визуальный инсет внутри scrollport, поверхность без влияния на layout. Заголовок группы — plain-строка над контейнером (Compact/Standard оба состояния, Detailed historical); headerless-состояния (Verbose, Detailed running, Detailed latest completed при On next message) — контейнер без заголовка; свёрнутая группа — plain-строка с выключенной поверхностью. Reasoning и context-injection внутри контейнера; раскрытые тела инструментов и ToolCallTree не меняются; независимые корни (turn-trigger, turn-error, turn-max-tokens, turn-tail, model-retry) вне контейнера, model-retry разрезает контейнер надвое; whale вне контейнера. README ui-chat (Grouped rendering, Turn Process Folding), conversation-nodes README и JSDoc обновляются в этом же тикете.

## Демо-путь

Собрать бандл ui-chat (`pnpm --filter @deepseek-ai/dsh-client-ui-chat bundle`) или держать `pnpm run dev:web`, обновить GUI. Живая сессия с процессом: в Verbose и в Standard с раскрытой группой тела групп лежат в тихих контейнерах, заголовки и реплики на чистом фоне; свёрнутая группа — plain-строка. Повторить в светлой и тёмной темах и на узкой ширине.

## Критерии приёмки (падают на базовом коммите)

1. Компонентная спека: в Verbose, Detailed running и раскрытой группе тело группы несёт оболочку с материалом (фон markdown-code-block, hairline border-l1, радиус lg). Артефакт: вывод `pnpm run test:gui` по новой спеке; ожидание: спека п.1 «Контейнер группы процесса». На базовом дереве оболочки нет — спека падает.
2. Компонентная спека: свёрнутая группа — plain-строка заголовка с выключенной поверхностью; переключение раскрытия не перемонтирует участников (disclosure-состояние и якорь сохраняются), высота заголовка постоянна. Артефакт: вывод test:gui; ожидание: спека п.1 (motion-контракт). На базовом дереве оболочки и критерия нет — спека падает.
3. Компонентная спека режимов: headerless-состояния дают контейнер без заголовка, состояния с заголовком — plain-заголовок над контейнером. Артефакт: вывод test:gui; ожидание: спека п.1 и п.4. На базовом дереве контейнера нет — спека падает.
4. Живая проба: контраст tertiary-текста на подложке контейнера в обеих темах; hairline-контуры вложенных карточек (общий токен заливки) различимы; двойных соседних рамок нет; sticky-баннеры код-блоков и breakout широких таблиц работают. Артефакт: снимки/запись пробы; ожидание: спека «Ограничения». На базовом дереве контейнера нет — пробовать нечего, критерий не выполняется.
5. Охранники: существующие спеки chat-view (режимы, сворачивание, scroll) зелёные. Артефакт: вывод test:gui; ожидание: спека п.4 «таблица режимов, группировка, folding, scroll ownership не меняются».
6. Документация: README ui-chat, conversation-nodes README, JSDoc ChatGroupSeat обновлены. Артефакт: вывод `pnpm run test:docs`; ожидание: спека п.6.
