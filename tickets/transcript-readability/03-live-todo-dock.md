# Тикет 3 — Живой список дел

Блокеры: нет.

## Зачем

Список дел над композером свёрнут в тихую полосу по умолчанию, хотя во время работы он важнее всего. Авто-раскрытие делает план видимым именно тогда, когда агент по нему работает — замечание оператора со скриншота.

## Что делает

[TodoPanel.tsx](../../packages/client/ui-conversation/src/client/skeleton/TodoPanel.tsx) раскрывается сам, пока сессия работает: сигнал `session.running` берётся из owner-пропсов `InputZone.session` (новый канал/хук/подписка не создаётся); триггер — состояние (непустая todo-проекция + running), а не только событие изменения, поэтому уже существующий план тоже раскрывает dock. Ручное сворачивание оператором подавляет авто-раскрытие до ухода сессии в idle; при idle dock сворачивается в полосу. Полоса получает прогресс-бар done/total (`aria-hidden`, новые ключи не нужны) рядом с существующими текстовыми счётчиками `todo.progress.*`; StateDot остаётся на раскрытых строках списка с существующим cap 180px со скроллом. README ui-conversation и JSDoc обновляются в этом же тикете.

## Демо-путь

Собрать бандл ui-conversation (`pnpm --filter @deepseek-ai/dsh-client-ui-conversation bundle`) или держать `pnpm run dev:web`, обновить GUI. Живая сессия с планом: во время работы dock раскрыт и показывает список со статусами; ручное сворачивание удерживается до idle; при idle — полоса с прогресс-баром и счётчиками. Повторить в светлой и тёмной темах.

## Критерии приёмки (падают на базовом коммите)

1. Спека todo-panel: running + непустая проекция → dock раскрыт, включая уже существующий план без события изменения; idle → свёрнутая полоса. Артефакт: вывод `pnpm run test:gui` по обновлённой [todo-panel.client.spec.tsx](../../packages/client/ui-conversation/tests/todo-panel.client.spec.tsx) (running через owner-пропсы); ожидание: спека п.3. На базовом дереве dock свёрнут по умолчанию при любом running — спека падает.
2. Спека ручного приоритета: ручное сворачивание во время running подавляет авто-раскрытие до idle; после idle и нового running авто-раскрытие снова работает. Артефакт: вывод test:gui; ожидание: спека п.3. На базовом дереве авто-раскрытия нет — спека падает.
3. Спека полосы: прогресс-бар done/total присутствует и aria-hidden; текстовые счётчики — существующие `todo.progress.*`; раскрытый список сохраняет StateDot и cap 180px. Артефакт: вывод test:gui; ожидание: спека п.3. На базовом дереве прогресс-бара нет — спека падает.
4. Живая проба: раскрытый список во время работы и полоса с прогрессом при idle в обеих темах; рост dock не ломает следование хвоста транскрипта. Артефакт: запись пробы; ожидание: спека п.3 и «Ограничения». На базовом дереве авто-раскрытия нет — критерий не выполняется.
5. Документация: README ui-conversation, JSDoc TodoPanel обновлены. Артефакт: вывод `pnpm run test:docs`; ожидание: спека п.6.
