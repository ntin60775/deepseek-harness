# Тикет 4 — Replay-refresh и финальная приёмка

Блокеры: тикет 1 (контейнер), тикет 2 (карточка финала), тикет 3 (живой список дел).

## Зачем

Контейнер, карточка и dock пишут одни и те же replay-expected (подпись финала попадает в каждый закрытый ход, прогресс-полоса — в queue-actions). Refresh до готовности всех UI-пунктов дал бы частичные конфликтующие диффы; отдельный блокирующий тикет собирает доказательство юнита целиком — ребро спеки.

## Что делает

Обновляет replay-expected затронутых сценариев после тикетов 1–3 с механическим критерием диффа; прогоняет финальные гейты; записывает GIF и несёт приёмку оператором. Сценарии с областью транскрипта: collapse-timing (`[data-chat-flow]`), deepseek-messages-chat (centerCol), subagent-conversation (включая `ui-expanded.expected.md`), queue-actions (dock); tool-details — охранник неизменности карточек инструментов. Масштаб churn: ≳40 сценариев, ~93 expected-файла в snapshots/web и ~106 в apps/web/tests/expected содержат реплики закрытых ходов.

## Демо-путь

`DSH_SNAPSHOT=replay pnpm run test:web` — полный зелёный прогон; просмотренный дифф expected содержит только строки подписи финала и прогресс-полосы. Собранный GUI с новой презентацией в обеих темах и на узкой ширине; записанный GIF демонстрирует контейнеры, карточку финала и живой dock.

## Критерии приёмки (падают на базовом коммите)

1. Механический критерий диффа: в diff expected-файлов допустима только новая строка подписи финала плюс строки прогресс-полосы в queue-actions/layout.expected.md; любой иной diff блокирует refresh. Артефакт: просмотренный `git diff` expected-файлов; ожидание: спека п.5. На базовом дереве обновлённых expected нет — критерий не выполняется.
2. Полный replay зелёный: `DSH_SNAPSHOT=replay pnpm run test:web` (полная сборка + сериальная сюита) проходит с обновлёнными expected. Артефакт: вывод команды; ожидание: спека п.5. На базовом дереве UI-изменений нет, обновлённые expected не совпадают — прогон падает.
3. Охранник tool-details: карточки инструментов не сдвинулись (снимок только карточек). Артефакт: вывод сценария tool-details; ожидание: спека п.5 (охранник неизменности).
4. Сводные гейты: `pnpm run test:gui` и `pnpm run test:docs` зелёные. Артефакт: вывод команд; ожидание: спека п.5–6.
5. GIF и приёмка: GIF записан по record-browser-gif и показывает контейнеры, карточку финала и живой dock в обеих темах; оператор принимает результат (дизайн-ревью через fallback dsh-client-ui-ux «When no approver holds that role»). Артефакт: GIF-файл и запись приёмки; ожидание: спека п.5 и «Ограничения». На базовом дереве новой презентации нет — GIF нечего снимать.
