# Тикет 2 — Карточка финального ответа

Блокеры: нет.

## Зачем

Промежуточная реплика и финальный ответ визуально идентичны, хотя данные уже знают финал хода. Карточка отделяет результат от потока речи — требование оператора, расширение поверх omp (omp финал не выделяет).

## Что делает

Рендерит карточку финала в [AssistantNodeView.tsx](../../packages/client/ui-chat/src/client/chat/AssistantNodeView.tsx) по предикату: `turn.status === 'closed'`, `turn-tail.closing.finalNode.seq === data.finalNode.seq` ([turn-tail.ts](../../packages/client/ui-chat/src/client/conversation-nodes/turn-tail.ts)), только response-место (`groupPart !== 'reasoning'`), только `turn/end.reason === 'completed'`; предикат не зависит от режима и партиального хвоста без turn/start. Края без карточки: открытый ход, закрытие без closing text-реплики, image-only финал, stopped/failed/interrupted/max-tokens. Материал — существующая приподнятая семья (QuestionComposer/PlanReviewPanel): `--dsw-specific-input-major`, `--dsw-radius-xl`, `border: 0`, hairline через `--dsw-elevation-panel`. Подпись «Окончательный ответ» / «Final answer» — новый ключ (например `message.finalAnswer`) во всех 8 словарях [locale.ts](../../packages/client/ui-chat/src/client/locale.ts); ключ `settings.foldedReplies.final` в транскрипте не потребляется. Промежуточные реплики plain; при свёрнутом процессе карточка сохраняется. README ui-chat и JSDoc обновляются в этом же тикете. Locale-ключ и карточка — один тикет (ребро спеки).

## Демо-путь

Собрать бандл ui-chat или держать `pnpm run dev:web`, обновить GUI. Завершённый ход (reason completed) в живой сессии: финальная реплика в приподнятой карточке с подписью, промежуточные реплики plain; то же в Verbose и при свёрнутом процессе. Повторить в светлой и тёмной темах; в тёмной сравнить карточку с соседними поверхностями.

## Критерии приёмки (падают на базовом коммите)

1. Компонентная спека предиката: закрытый completed-ход с closing text-репликой даёт карточку на response-месте; края (открытый ход, промежуточная реплика, image-only, stopped/failed/interrupted/max-tokens, reasoning-место) — без карточки. Артефакт: вывод `pnpm run test:gui` по новой спеке; ожидание: спека п.2. На базовом дереве карточки нет — спека падает.
2. Спека подписи и словарей: карточка несёт подпись из нового ключа; ключ присутствует во всех 8 словарях (locale-parity). Артефакт: вывод test:gui (включая locale-dictionary-parity); ожидание: спека п.2 «новый ключ во всех 8 словарях». На базовом дереве ключа нет — спека падает.
3. Спека материала и режима: карточка использует specific-input-major + radius-xl + elevation-panel + border:0; присутствует в Verbose и при свёрнутом процессе. Артефакт: вывод test:gui; ожидание: спека п.2 и п.4. На базовом дереве карточки нет — спека падает.
4. Живая проба: разделение карточки с фоном страницы в тёмной теме и с соседними приподнятыми/утопленными поверхностями в обеих темах. Артефакт: снимки пробы; ожидание: спека п.5 (сравнение поверхностей). На базовом дереве карточки нет — критерий не выполняется.
5. Документация: README ui-chat, JSDoc AssistantNodeView обновлены. Артефакт: вывод `pnpm run test:docs`; ожидание: спека п.6.
