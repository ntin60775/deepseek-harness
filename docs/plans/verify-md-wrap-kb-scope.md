# Сузить корпус verify-md-wrap под KB-оверлей

## Зачем

Правило «каждый абзац — одна физическая строка» принадлежит документации DSH и её гейту `pnpm run verify-md-wrap`. Файлы, которые переносит метод OntoShip, этому правилу не подчиняны и подчинять их нельзя: `docs/ontology.md` обязано быть побайтовым зеркалом поставленной модели (инвариант I8 в `.agents/skills/kb-search/gitmark.py`), а зеркало приходит перенесённым; `docs/ops/continue.md` и спеки `docs/plans/` пишет оператор и скиллы метода. Сейчас из-за этого `verify-md-wrap` красен на `docs/ontology.md` (6 абзацев) и был красен на блоке `<!-- BEGIN ontoship -->` в `AGENTS.md` (8 абзацев, перебиты в прогоне онто-дока 2026-11-10).

## Цель

Гейт перестаёт падать на носителях KB-оверлея, не ослабляя проверку ни для одного документа DSH.

## Готово

Носители, по которым принимается тикет:

1. `scripts/verify-md-wrap.ts`: корпус не включает `docs/ontology.md`, `docs/ops/**`, `docs/plans/**`, `docs/reference/**`; в `AGENTS.md` регионы между `<!-- BEGIN ontoship -->` и `<!-- END ontoship -->` маскируются до разбора, по аналогии с уже маскируемым VitePress-frontmatter.
2. `scripts/verify-md-wrap.spec.ts` создаётся и накрывает три случая: перенесённый абзац в `docs/ontology.md` принимается; перенесённый абзац внутри онтошиповских маркеров принимается; перенесённый абзац в обычном документе отклоняется. Первые два случая падают на базовом коммите, третий не меняется относительно базового.
3. `docs/AGENTS.md` получает одно предложение об исключении корпуса рядом с правилом `verify-md-wrap`; файл в исключениях пейринга, так что правка только английской стороны.
4. `pnpm run test:docs` зелёный на рабочем дереве прогона; `pnpm run doc-sync` не добавляет новых падений.

## Рамки

Меняются только `scripts/verify-md-wrap.ts`, новый `scripts/verify-md-wrap.spec.ts` и правило в `docs/AGENTS.md`. PATTERNS для `README.md`, `packages/**`, `snapshots/**`, `.agents/notes/**` и остальных `docs/**` остаются как есть. Никаких новых флагов командной строки, никаких правок в `.agents/skills/**` (поставляемый движок и скиллы — не этот репозиторий).

## Ограничения

I8 сравнивает проектную копию онтологии с поставленной от первого заголовка `## `, поэтому перебить переносы в `docs/ontology.md` нельзя: останется постоянный WARN в `gitmark lint`. Победивший вариант — сузить корпус гейта, а не привести носитель к правилу. Альтернатива «вычеркнуть `docs/ontology.md`» не рассматривается: без проектной копии I2 читает словарь из кода движка и перестаёт быть проверяемой.

## Демо-путь

`pnpm run verify-md-wrap` → зелёный. Затем вручную перенести абзац в `docs/architecture.md`, перезапустить → красный, в выводе этот файл; откатить правку.

## Связи

Закрытие этого тикета снимает последнее падение `verify-md-wrap` в прогоне онто-дока 2026-11-10. Сам тикет ничему не блокирует работу; блокатора нет. Родственный долг по бюджету `AGENTS.md` описан в `docs/ops/continue.md` и идёт отдельным тикетом.
