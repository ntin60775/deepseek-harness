# Разделить бюджет `AGENTS.md` на тело и KB-регион

## Зачем

`pnpm run verify-doc-budgets` считал корневой `AGENTS.md` целиком против апстримской планки 2080 и падал: 2252 слов, из них 172 добавляет регион `<!-- BEGIN ontoship -->`…`<!-- END ontoship -->`. Подъём планки под оверлей обесценивает её: апстрим держит 2069 из 2080, и каждый следующий мерж открывал бы в ней новую дыру. Тело и регион считаются теперь раздельно.

## Готово

Носители, по которым принимается работа:

1. [scripts/verify-doc-budgets.ts](../../scripts/verify-doc-budgets.ts) собирает аудит в `auditDocBudgets(root, manifest)` и знает ключи `<path>#<token>`: регион между строками-маркерами считается вместе с маркерами, запись `<path>` вычитает все регионы, объявленные для этого файла. Отсутствие маркеров — `MISS` с именем токена, а не молчаливый перенос региона в тело.
2. [scripts/doc-budgets.manifest.json](../../scripts/doc-budgets.manifest.json) несёт `"AGENTS.md": 2080` (апстримское число не тронуто) и `"AGENTS.md#ontoship": 200`.
3. [scripts/verify-doc-budgets.spec.ts](../../scripts/verify-doc-budgets.spec.ts) — шесть случаев: тело считается без региона; регион имеет свой потолок и падает отдельно; при отсутствии ключа-региона считается весь файл; сломанные или отсутствующие маркеры дают `MISS`; отсутствующий файл, нулевая планка и битый ключ сохранены как падения.
4. [docs/AGENTS.md](../AGENTS.md) описывает форму ключа `<path>#<token>` одним предложением в разделе «Wordcount Budgets».
5. Итог на рабочем дереве: `AGENTS.md` 2080/2080, `AGENTS.md#ontoship` 172/200, гейт зелёный; `pnpm run test:docs` не добавляет падений.

## Рамки

Механизм живёт в гейте и манифесте: новых флагов командной строки нет, `--list` печатает строку на каждый ключ, формат строк сохранён. Правок в `.agents/skills/**` нет. Апстримские планки остальных стоячих документов не менялись.

## Ограничения

Тело `AGENTS.md` занимает 2080 из 2080 — ровно планку. Апстрим держит 2069 из 2080, то есть тоже без запаса по правилу «≥5% запаса» из [docs/AGENTS.md](../AGENTS.md); этот запас — предмет ревью апстрима, а не форка, и форк его не отменяет. Первый же апстрим-мерж, добавивший в `AGENTS.md` слово, вернёт gate-красный: тогда по той же docs/AGENTS.md-последовательности сначала relocate, потом condense, и только потом планка с обоснованием в PR. Регион `ontoship` при этом остаётся ограниченным 200 словами и не может разрастаться молча.

## Демо-путь

`pnpm run verify-doc-budgets -- --list` → строки `ok` на `AGENTS.md` и `AGENTS.md#ontoship`. Затем временно добавить тридцать слов внутрь онтошиповских маркеров → `AGENTS.md#ontoship` идёт в `OVER 202 / 200`, а `AGENTS.md` остаётся `ok 2080 / 2080`; убрать добавленное обратно.
