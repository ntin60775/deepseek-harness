# Mermaid-диаграммы в чате — единый режим A через fence-слой ui-mermaid

## Цель

Огороженный блок ` ```mermaid ` в транскрипте чата рендерится в SVG-диаграмму вместо код-блока ([ишью форка #9](https://github.com/ntin60775/deepseek-harness/issues/9)). Один тип карточки для всех размеров и тем: диаграмма по умолчанию, исходник по кнопке. Пакет `packages/client/ui-mermaid` подключается opt-in строкой бандла. Спека утверждена на план-гейте 2026-11-16 и обновлена пакетом правок гейта проекций решением оператора 2026-11-16 ([отчёт](../../tickets/mermaid-fence-render/projections.md)).

## Готово

Каждый пункт назван с носителем доказательства. Термин: settled fence = `fence.streaming === false` (уровень fence, не turn).

0. **Скелет и поверхности регистрации.** Пакет `@deepseek-ai/dsh-client-ui-mermaid`: manifest (`exports["./client"]`, `dsh.client` с `platform: 'web'` и inject-рёбрами), `tsconfig.client.json` reference, `tsdown` clientBundle, `files` glob `lib/client*.js` + запись `packageFileExtras`, зависимость в `packages/bundle/web-app/package.json`, classification-запись `PRODUCT_PACKAGE_POLICY` (optional), README-скелет. Носители: `verify-client-packages`, `verify-cordis-config`, `build:artifacts`, `pnpm run hygiene`.
1. **Locale первым срезом.** Typed dictionary namespace `mermaid`, регистрация `locale: NS`, метаданные по всем shipped-языкам (8 locale JSON). Носители: `verify-locale-metadata`, `verify-client-ui-i18n`, `check:i18n`.
2. **Sanitize до любого рендера.** DOMPurify default-профиль + `FORBID: ['foreignObject']` (svg-профиль срезает `role` — не используется); глобальный `htmlLabels: false` (`flowchart.htmlLabels` deprecated). Инвариант после sanitize: в SVG есть непустые текстовые узлы, иначе тот же путь деградации, что и ошибка парсинга (код-блок + notice). `<use>` вырезается DOMPurify всегда — встроенные SVG-иконки не поддерживаются (ограничение). Сохранность корня после sanitize: `viewBox`, `role`, `aria-label`, `class`, `style`, `marker-*`. Векторы (flowchart HTML-лейбл, `click href "javascript:"`, `click call`, sequence HTML-лейбл, пустой текст) — коммитируемая фикстура PR с полными mermaid-исходниками и записанным SVG-выводом Chromium. Носители: регрессионная спека на фикстуре (jsdom): нет live HTML, текст виден, атрибуты корня на месте.
3. **Четыре состояния тела.** Стриминг → `children` passthrough без изменений; settled + чанк грузится → тот же код-блок; settled + рендер → SVG-карточка; ошибка парсинга или отказ `import()` → код-блок + компактный notice, исходник сохранён; политика повтора импорта: без повтора, новая попытка на монтирование. Компонентные спеки исполняются на зафиксированном SVG-выводе фикстуры (jsdom не рендерит mermaid: `getBBox` отсутствует); настоящий settle-рендер доказывается только web-сценарием. Носители: компонентные спеки каждого состояния (mock resolve/reject импорта, passthrough, notice), web-сценарий.
4. **Шапка, исходник, просмотрщик.** Шапка: `mermaid` · «Исходник» (`aria-pressed`) · «Копировать» · открытие в просмотрщике; Enter/Space на сфокусированной обёртке открывает просмотрщик. «Исходник» свапает тело на `CodeBlock` с `showHeader={false}` и обратно; копирование доступно в обоих состояниях. Просмотрщик — существующий `ImageLightbox` с data: URL (`base64` от UTF-8 байтов) сериализованного SVG с явными `width`/`height` из `viewBox`; семантика — viewport-fit: лайтбокс вписывает диаграмму во вьюпорт (капы `min(100%, 1600px)` / высота вьюпорта), абсолютного 1:1 нет; в широкой ветке просмотрщик показывает диаграмму целиком без обрезки колонкой. `alt` и метки лайтбокса — locale. Отказ загрузки img не ожидается (источник — собственный сериализованный SVG); регрессия кодировки ловится спекой. Носители: спеки свапа/copy/фокуса/`aria-pressed`/Enter, спека явных width/height и кодировки (кириллический лейбл + широкая фикстура).
5. **Правило вписывания.** `fit = min(1, measureWidth / W)`; `W×H` — `viewBox.baseVal` (jsdom читает baseVal, проверено). `measureWidth` — `clientWidth` внутреннего непрокручиваемого measure-контейнера карточки (скроллбар исключён, значение не зависит от режима); ширина инжектируется apply-owned ref-callback лицом измерения (прецедент [header-scroll.ts](../../packages/client/ui-plugin-manager/src/client/header-scroll.ts)); fit — чистая функция `(viewBox, injectedWidth, config)`. `fit < minFitScale` → натуральная ширина (явные width/height) + горизонтальный скролл внутри карточки; иначе вписывание в колонку (`useMaxWidth` default: `width="100%"` + `max-width`); равенство → вписанный режим. ResizeObserver без debounce, порог применяется в колбэке; перерисовка mermaid на ресайз запрещена (смена режима = атрибуты корня/CSS из кэшированного SVG). Высота не ограничивается. Носители: граничные спеки чистой функции (0.84 / 0.85 / 0.86), спека RO-подмены (переключение режима, коалесцирование), не-golden браузерная проверка web-сценария (`scrollWidth > clientWidth` / `data-fit-mode`), узкая ширина ассертится web-сценарием.
6. **Тема.** 6a: маппинг `themeVariables` ← семантические `--dsw-*` — чистая функция; разрешённые значения читаются `getComputedStyle` в async-шаге операции рендера (после записи presenter'ом ui-layout), публикуются через inject `hooks` compartment стабильным иммутабельным снимком; начальное значение `ctx.theme.getTheme()` при `theme` в inject; компонент подписок и live-чтений в render не создаёт. 6b: `theme/change` → новая попытка рендера через контроллер (п.7), перерисовка без перезагрузки. Метрики и правило от темы не зависят: базовый шрифт диаграммы фиксирован 13px. Носители: jsdom-спека на собственном style-фикстуре с литеральными значениями (чтение в момент рендера + re-render на fixture `theme/change`; jsdom не разворачивает `var()`/`color-mix`), CSS-text спека имён токенов (прецедент `*-styles.client.spec.ts`), живая проба light/dark и OMP TUI.
7. **Контроллер рендера.** Одна асинхронная операция — один lifecycle-контроллер попытки: уникальный render id, generation-token, отброс результата со старым токеном, cancel/cleanup на unmount, повторный settle и смена темы = новая попытка; сериализация рендеров между карточками (mermaid глобален: singleton db, общий конфиг) владельцем-инстансом в apply/hooks, не модульным синглтоном. Носители: спеки «stale theme render отброшен», «unmount во время рендера», «две карточки одновременно», «повторный settle».
8. **Доступность.** Обёртка `role="img"` + локализованный `aria-label` (имя владеет locale-строка; mermaid-овские `aria-labelledby`/`accTitle` снимаются), внутренний `svg` с `aria-hidden="true"`; `tabindex=0` + Enter/Space → просмотрщик; lightbox наследует focus-restore. ARIA-проекция web-снапшота = ровно одна строка `- img "<label>"` (замерено: subtree role=img не прунится без aria-hidden). Носители: ARIA-голден web-сценария, спека фокуса/клавиш/атрибутов.
9. **Opt-in строка и web-доказательство.** Строка ростера `insert:`: `- id: ui-mermaid` / `name: '@deepseek-ai/dsh-client-ui-mermaid'` / `disabled: true` (литеральный прецедент [base/cordis.patch.yml:16-19](../../packages/bundle/base/cordis.patch.yml)); правило opt-ins — [testing.md:39](../testing.md). Включение в web-сценарии — overlay `disabled: false` по shipped-id (прецедент [sidebar-browser.overlay.yml](../../apps/web/tests/sidebar-browser.overlay.yml)), не `insert:`; положительная строка диаграммы в `ui.expected.md` обязательна — охранник тихого промаха оверлея (несовпавший id в общем патчере только warn). Composition-спека проверяет `row.name` → workspace-манифест с `dsh.client.platform: 'web'` + зависимость бандла. Web-сценарий — load-bearing base-proof: на базовом дереве строки нет → fence = код-блок → golden расходится; компонентные спеки — мутационные пробы (снятие ветки fit/notice/sanitize краснеет); «падает отсутствием пакета» доказательством не считается. Сценарий явно ждёт `role=img`/имя до снятия снапшота (`captureStableAria` снимает два равных снимка, код-блок стабилен). Носители: composition-спека, `DSH_SNAPSHOT=replay pnpm run test:web`, запись base-proof.
10. **Ленивый бандл и раскрытие.** `import()` указывает на локальный модуль пакета; форма бандлинга mermaid-входа — single-chunk / inline dynamic imports (внутренние 38 import'ов mermaid не выпускают отдельный граф); все эмитуемые `lib/client*.js` self-contained, glob в `files` + `packageFileExtras`. `clientBanner` лицензионного раскрытия по имени чанка (прецедент [ui-sidebar-documentpreview/tsdown.config.ts](../../packages/client/ui-sidebar-documentpreview/tsdown.config.ts)) покрывает установленный dependency-closure mermaid — каждый пакет, чей код эмбитится в чанк (поправка решением оператора 2026-11-17: исходный перечень d3/cytoscape/katex/marked/roughjs не был исчерпывающим, в чанке 56 пакетных корней); dompurify транзитивен через mermaid — одна копия. Реестр `THIRD_PARTY_NOTICES.md` раскрывает тот же closure для каждого распространяемого browser-входа (генератор обходит дерево зависимостей, распространение перебивает dev-декларацию). Пины: `mermaid` ровно `11.17.2` (website-пин — источник дрейфа), `dompurify ^3.4.16`. Носители: пакетная bundle-split спека (прецедент [bundle-split.client.spec.ts](../../packages/client/ui-sidebar-terminal/tests/bundle-split.client.spec.ts)) пинит `require.async("./client.<name>.js")` и фактический набор emitted-чанков; `gen/verify-third-party-notices`; разовый замер размеров артефактов до/после в PR (новый gate не строится).
11. **Документы и генерации.** README `ui-mermaid` с Model Experience, Agent Note решения; перегенерации `gen-client-catalog` / `gen-config-catalog` / `gen-module-graph` / `gen-dependency-catalog` / `gen-third-party-notices`. Носители: `pnpm run test:docs`, `pnpm run doc-sync`.
12. **Контур.** `pnpm run test:gui` + `DSH_SNAPSHOT=replay pnpm run test:web` (включает build); `build:check` отдельной последней строкой после `build:artifacts`; `pnpm run hygiene`; per-file 100% coverage тронутого src локально (полный гейт владеет CI); мутационные пробы компонентных спек; живые пробы light/dark/OMP TUI (узкая ширина — web-сценарий, отдельная проба не нужна).

## Рамки

- Слой регистрируется через `ctx.slots.inject('conversation.chat.markdown.fence', …)` точным объектом `{ name: 'conversation.chat.markdown.fence', key: 'mermaid', id: '@deepseek-ai/dsh-client-ui-mermaid/fence/mermaid', locale: 'mermaid', inject }`; `children` не декларируются; стриминг-ветка рендерит `children` проп passthrough ([ChatView.tsx:114](../../packages/client/ui-chat/src/client/chat/ChatView.tsx), [slots.ts:433](../../packages/client/ui-chat/src/client/contract/slots.ts), прецеденты [register.ts](../../packages/client/ui-chat/src/client/fence/register.ts)). Новые extension points не вводятся.
- Шапка карточки — собственный компонент `ui-mermaid` на токенах темы (`CodeToolbar` не несёт «Исходник» и просмотрщика). Тело-исходник — `CodeBlock` ([CodeBlock.tsx](../../packages/client/ui-primitives/src/markdown/CodeBlock.tsx)) с `showHeader={false}`; просмотрщик — `ImageLightbox` ([ImageLightbox.tsx](../../packages/client/ui-primitives/src/ImageLightbox.tsx)). Оба из `ui-primitives` — статического общего владельца в baseline `PLATFORM_MODULES`; `dsh.client.external` для них и для mermaid/dompurify не объявляется (silence = private copy).
- Измерение ширины — apply-owned ref-callback лицо (прецедент [header-scroll.ts](../../packages/client/ui-plugin-manager/src/client/header-scroll.ts)); три ответа правила записаны: CSS не сравнивает viewBox-ширину конкретной диаграммы с колонкой через порог, значение пиксельное, владелец — узел карточки; бизнес-прецедент observer'а узла — [DeliveryHistory.tsx](../../packages/client/ui-schedule/src/client/DeliveryHistory.tsx); подтверждение домен-эксперта фиксируется в диффе на ship.
- Канал темы: `ctx.on('theme/change')` в apply ([index.ts:144](../../packages/client/ui-theme/src/client/index.ts)) → inject `hooks` compartment; разрешённые значения — async-шаг рендера, не render компонента.
- Контроллер рендера и сериализация — инстанс в apply/hooks; модульных синглтонов нет.
- Host, `agent-loop`, session-формат не меняются: рендер — чистая презентация существующего fence-события. `ui-primitives` не меняется (viewport-fit семантика использует существующие капы лайтбокса).

## Ограничения

- Вне объёма ишью: другие языки диаграмм (graphviz/plantuml/d2), экспорт/редактирование/WYSIWYG, рендер в заголовке сессии, карточках инструментов и превью `.md`.
- Встроенные SVG-иконки (`<use>`) не поддерживаются: DOMPurify вырезает `use` всегда; диаграмма с иконками рендерится без них, пустой текст деградирует по инварианту п.2.
- Интерактивного зума нет; просмотрщик — viewport-fit с капами лайтбокса, не абсолютный 1:1.
- Санитайзер только DOMPurify одним конфигом (default-профиль + FORBID foreignObject); свой обход SVG-дерева запрещён; `htmlLabels: false` глобально.
- Пиксельных снапшотов нет; ARIA-голден = одна строка обёртки (`aria-hidden` на внутреннем svg); контент диаграммы доказывается компонентной спекой на фикстуре.
- Строка бандла выключена по умолчанию ([testing.md:39](../testing.md), прецедент base:16-19); upgrade guide не нужен, пока поведение не включено shipped-профилем.
- `minFitScale` — Config-поле `(0, 1]`, дефолт 0.85 (округление вверх 11/13 ≈ 0.846), валидация при загрузке, misconfig fails loud; кейс равенства — вписанный режим. Базовый шрифт диаграммы 13px и floor 11px — фиксированные дизайн-константы, не Config.
- Per-file 100% coverage на `ui-mermaid/src`; REAL-composition доказательство — `test:web` replay; load-bearing base-proof — web-сценарий, компонентные спеки — мутационные пробы.
- Copy locale-owned: все строки пакета через typed dictionary и `t`; хардкод copy запрещён.
- e2e кастомной темы (OMP TUI) в репо нет: тема — локальный плагин вне репозитория; проверка — живая проба вручную.
- Ресайз: ResizeObserver без debounce, без перерисовки mermaid; смена режима — атрибуты корня/CSS из кэшированного SVG.

## Контекст

Факты с путями:

- Точка расширения существует: session-scoped HOC-слот `conversation.chat.markdown.fence`, `entryKey` = язык fence; слой без `children` заменяет код-блок, стриминг-ветка получает `children` пропом ([ChatView.tsx:114](../../packages/client/ui-chat/src/client/chat/ChatView.tsx), [slots.ts:433](../../packages/client/ui-chat/src/client/contract/slots.ts), [register.ts](../../packages/client/ui-chat/src/client/fence/register.ts), [ui-slots/index.ts:825-839](../../packages/client/ui-slots/src/index.ts)).
- mermaid 11.17.2 уже в node_modules как зависимость website ([website/package.json:18](../../website/package.json)); прецедент чтения `viewBox.baseVal` — [mermaid-viewer.ts](../../website/.vitepress/theme/mermaid-viewer.ts). Mermaid глобален: singleton db, `initialize()` мутирует общий конфиг, `removeExistingElements` по id; `useMaxWidth` default пишет `width="100%"` + `max-width`; `flowchart.htmlLabels` deprecated, эффективный ключ глобальный `htmlLabels`; часть семейств эмитит foreignObject без гейта.
- Спайк strict-режима (локально `.scratch/mermaid-mockups/spike-strict.html`): `securityLevel: 'strict'` пропускает live `foreignObject` с `<img src="x">`; JS и event-хендлеры вырезаются, элементы — нет. DOMPurify 3.4.16: default-профиль сохраняет `role`, svg-профиль — нет; `use` в svgDisallowed всегда; `viewBox`/`style`/`class`/`marker-*`/`defs` сохраняются.
- `ImageLightbox` — portal-модалка с `<img src>`, капы `max-width: min(100%, 1600px)` / `max-height: 100%` / stage padding 40px ([ImageLightbox.module.css:26-29](../../packages/client/ui-primitives/src/ImageLightbox.module.css)), без интерактивного зума и без size-режима; SVG в data: URL внутри `<img>` инертен к скриптам.
- Web-снапшоты — Playwright `locator.ariaSnapshot()` ([scaffold.ts:1690](../../apps/web/tests/scaffold.ts)), нормализация и сравнение там же; `captureStableAria` ждёт два равных снимка ([scaffold.ts:1689-1700](../../apps/web/tests/scaffold.ts)); subtree `role="img"` не прунится без `aria-hidden` (замер Chromium); формат голдена — [snapshots/web/code-language/ui.expected.md](../../snapshots/web/code-language/ui.expected.md).
- jsdom-факты (замеры): `mermaid.render` падает `getBBox`; `getComputedStyle` не разворачивает `var()`/`color-mix` (алиасы читаются литералами), листы тем в component-спеках не подключены; `viewBox.baseVal` читается; layout/ResizeObserver отсутствуют.
- Overlay-включение выключенной shipped-строки — `disabled: false` по id ([sidebar-browser.overlay.yml](../../apps/web/tests/sidebar-browser.overlay.yml), [scaffold.ts:577-586](../../apps/web/tests/scaffold.ts)); несовпавший id в общем патчере только warn ([vendor/include/src/patch.ts:93](../../vendor/include/src/patch.ts)).
- Правила владельца: реактивные каналы и measurement — [packages/client/AGENTS.md](../../packages/client/AGENTS.md) и [defensive-patterns/client-components.md:312-317](../defensive-patterns/client-components.md); один async-контроллер и владелец shared state — [packages/AGENTS.md](../../packages/AGENTS.md); opt-ins — [testing.md:39](../testing.md); лицензионное раскрытие приватных копий — [client AGENTS:69](../../packages/client/AGENTS.md), прецедент `clientBanner` — documentpreview.

Решения оператора:

Тривиальные решения агента по фильтру раундов (обратимые, маловлияющие):

- Базовый шрифт диаграммы фиксирован 13px во всех темах; OMP-макет переснят с 13px.
- ResizeObserver без debounce (прецедент HoverCard debounce не содержит; RO коалесцирует по кадрам); notice при ошибке сохраняется; отказ import — тот же notice-путь.
- Кодировка data: URL — base64 от UTF-8 байтов; имя диаграммы владеет locale-строка, mermaid-овский `aria-labelledby` снимается.
- Fixture web-сценария авторский keyless (`session.vN.jsonl` с mermaid-fence), запись модели не нужна; векторы sanitize — коммитируемая фикстура PR.
- Инвариант непустого текста — единый путь деградации для пустого рендера и ошибки парсинга; per-family векторы не строятся.

Макеты всех вариантов и состояний (light/dark/OMP TUI) — локально `.scratch/mermaid-mockups/` (`mockup.html?v=a|b|c|d|states|viewer|hybrid&theme=light|dark|omp`), эфемерные, не коммитятся.
