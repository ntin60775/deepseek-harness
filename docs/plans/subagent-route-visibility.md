# Маршрут субагента виден — строка в каталоге и чип в карточке спавна

## Цель

Каталог субагентов и карточка спавна показывают описание, имя, статус, токены и время, но не показывают, на каком провайдере/модели и с каким reasoning effort работает ребёнок; унаследованный маршрут не виден вовсе, а явный выбор виден только в раскрытых аргументах. Цель — записанный выбор модели `provider/model` + effort виден без раскрытия: третьей строкой в каждом ряду каталога (макет 1) и чипом в шапке карточки `subagent`/`subagent_fork` (макет 3). Принятые макеты: [m1-catalog.png](../../tickets/subagent-route-visibility/mockups/m1-catalog.png), [m3-spawn-card.png](../../tickets/subagent-route-visibility/mockups/m3-spawn-card.png) (трекемая копия; легенды макетов не являются контрактом).

## Решения гейта

Один дом принятых решений; пункты «Готово» ссылаются на них без повторения.

- План-гейт 2026-11-13, оператор: макеты 1+3 приняты, макет 2 (бейдж в шапке ребёнка и read-only метка в композере) отложен; при неявном effort — локализованный чип «default»; канал данных карточки — клиентский поиск по имени в каталоге родителя; до первого запроса ребёнка чип из явных аргументов, иначе скрыт; аннотации наследования нет; полный доказательный контур с replay-refresh блокирующим тикетом; спека утверждена.
- Гейт проекций 2026-11-13, оператор (отчёт [projections.md](../../tickets/subagent-route-visibility/projections.md)): пакет правок по 24 подтверждённым находкам применён; D1 — assembled-носитель чипа: расширение `subagent-conversation` записанным вызовом `subagent` с producer-meta `{kind, name:'agent-1'}` под существующий ряд каталога; D2 — name-tag макета 3 вне объёма v1, чип привязан к существующей шапке; D3 — граница v1: маршрут из дескриптора не показывается до первого `request/header`, projection-канал не расширяется.
- Пул валидации 2026-11-13, оператор: секция `[validation]` реестра `.agents/config.toml` добавлена со стандартной раскладкой flash-пула.
- Решение оператора 2026-11-13 после приёмки тикета 01 (живая проба в GUI): ширина выпадающей панели — по длине содержимого (`fit-content`, пол 360px, потолок `min(560px, 100vw − 32px)`); маршрут — две строки: имя провайдера на первой, имя модели + чип effort на второй. Макет 1 в части одной строки маршрута и фиксированной ширины 360px этим решением заменён; тикет 04 несёт правку.

## Готово

Термины: маршрут = `provider/model` (код-токены verbatim); effort — отдельный чип; слово «путь» для строки роута не используется (в коде route = provider/model без усилия, «путь» занят агентным путём). Значение — записанный выбор модели (`modelSelection`: `next ?? lastUsed`), не «резолвнутый»: проекция не разрешает дефолты адаптера и не содержит унаследованный маршрут до первого запроса; приоритет pending/next над lastUsed — без fallback на живые AgentOptions.

Носители, по которым принимается работа:

1. **Строка маршрута в каталоге.** В [SubagentHeaderLineage.tsx](../../packages/client/ui-subagent/src/client/SubagentHeaderLineage.tsx) каждый локальный ряд (`CatalogRows`) получает двухстрочный блок маршрута под именем (решение оператора 2026-11-13): первая строка — verbatim имя провайдера, вторая — verbatim имя модели рядом с чипом effort 10px на приподнятой заливке темы с радиусом `--dsw-radius-xs`; обе строки 11px/16px приглушёнными чернилами темы. Блок выравнивается по колонке имени (наследует отступ ряда, включая disclosure-колонку) и живёт внутри `.clickarea`, чтобы hover/focus-заливка ряда накрывала его; чип effort не сжимается, каждая строка уходит в ellipsis. Значение — `modelSelection` дочерней сессии из `summaries[entry.id].projectionValues` тем же каналом, что `tokenUsage`/`subagentTiming`; pending-переключение у адресованного ребёнка недостижимо (селектор скрыт, `model/selection` в его логе не появляется) и отдельного носителя не требует. Effort отсутствует → локализованный чип «default» со смыслом «явного выбора не было, решает адаптер»; id effort — verbatim. Скрытые состояния: projection-значение пусто (ребёнок до первого `request/header`; маршрут из дескриптора в v1 не показывается — D3); external (локальной сессии нет); unknown (локальный ребёнок v1, маршрут может быть записан — скрыт по границе объёма); migration-required (сигнал `summaries[id].formatStatus` или состояние дочернего каталога, не `entry.mode`). Fork-ребёнок: унаследованный `lastUsed` считается записанным маршрутом и показывается с создания без аннотации. Длинный провайдер или модель — ellipsis + Tooltip с полным маршрутом `provider/model`; на touch — tap-to-show через существующий `openOnClick` (dsh-responsive-ui §7.2), полный маршрут также в `aria-label` ряда; строка маршрута входит в `aria-label`. Ширина меню — по содержимому: `fit-content` между полом `min(360px, 100vw − 32px)` и потолком `min(560px, 100vw − 32px)` (решение оператора 2026-11-13); ряд растёт только по высоте на две строки маршрута; перенос описания, колонка метрик, disclosure-геометрия и коннекторы ветвей (якорь от верха ряда) не меняются. Носитель: компонентные спеки состояний (маршрут есть/нет, default-чип, fork-наследование, external/unknown/migration-required, aria-label, присутствие tooltip) с падением на базовом src; усечение — e2e узкой ширины либо глазная проба (jsdom без лейаута); проба scaffold обеих тем, узкой ширины (viewport < 392px, ряд уровня 2) и touch; replay-голдены сценариев каталога; cold-ассерт (Ограничения).
2. **Чип маршрута в карточке спавна.** В [details-row.tsx](../../packages/client/ui-tool/src/client/tool/toolviews/details-row.tsx) свёрнутая шапка карточек `subagent`/`subagent_fork` получает чип маршрута между локализованным заголовком и правой капсулой времени/disclosure; name-tag макета 3 в v1 не входит (D2), легенды макетов неконтрактны. Данные: `meta.name ?? args.name` → ряд `subagentCatalog` родителя через `useSessions` (framework standing seat) → `summaries[childId].projectionValues.modelSelection` (`next ?? lastUsed`). До первого запроса ребёнка — чип из явных аргументов `provider/model/reasoning_effort` только когда прочитаны оба `provider` и `model` (частичные аргументы стримящегося вызова → чип скрыт); отсутствующее усилие → «default»; аргументов маршрута у `subagent_fork` в shipped-пресетах нет → чип появляется с проекцией. Fork-карточка: унаследованный маршрут показывается с создания. Исторические ряды без имени и external-исполнения чипа не получают; аннотации наследования нет. Output-схема инструмента и `presentationMeta` не меняются: канал чисто клиентский. Носитель: компонентные спеки резолва, фолбэка аргументов (включая частичные), скрытых состояний и fork с падением на базовом src; assembled-носитель — расширенный `subagent-conversation` (D1): записанный вызов `subagent` с producer-meta `{kind, name:'agent-1'}` под существующий ряд, чип виден без раскрытия; пустой diff в чип-носителе = падение тикета; `subagent-summary` и `tool-details` остаются охранниками скрытого состояния (карточки без имени → чипа нет, голдены не меняются).
3. **Словари.** Новые ключи (подпись чипа «default», aria/tooltip маршрута) во всех 8 словарях [ui-subagent locales.ts](../../packages/client/ui-subagent/src/client/locales.ts) — за строку каталога, и во всех 8 словарях `conversation` NS [ui-conversation locales.ts](../../packages/client/ui-conversation/src/client/locales.ts) — за чип карточки (ui-tool своих продуктовых словарей не владеет, `locale.ts` — только `CONVERSATION_NS`); подпись «default» согласована между поверхностями. Носитель полноты ключей — типы и `build:check` (`Record<SubagentKey, string>` / `ConversationKey`); `verify-client-ui-i18n` — «нет захардкоженной копии».
4. **Доказательный контур.** `pnpm run test:gui` — без новых падений относительно базового списка чужих падений (docs/ops/continue.md); per-file coverage 100% на тронутом src ui-subagent/ui-tool/ui-conversation; lint/oxlint по тронутым пакетам; `build:artifacts` + `build:check`; живая проба на собранном бандле через keyless scaffold (`launchWebScaffold`, chromium установлен) — обе темы, узкая ширина (viewport < 392px, ряд уровня 2) и touch, скриншоты читает исполнитель, проба не коммитится; replay: detect → refresh → повторный зелёный прогон с механическим критерием (Ограничения); cold-ассерт `modelSelection` в существующем cold-read-участке e2e; `pnpm run test:docs` без новых падений; приёмка оператором как designer fallback по dsh-client-ui-ux; GIF при наличии PR-пути, иначе скриншоты пробы; push без команды оператора не делается. Носитель: выводы команд и прочитанные скриншоты в отчёте тикета.
5. **Документация.** README ui-subagent (строка маршрута в ряду каталога) и README ui-tool (чип карточки) описывают новую презентацию; JSDoc затронутых компонентов обновлён в том же изменении. Носитель: `pnpm run test:docs`.

## Рамки

Макет 2 отложен и в юнит не входит; name-tag макета 3 вне объёма v1 (D2). Новых настроек, session-событий, проекций и пакетов нет; host-пакеты и model-visible контракты (output-схема инструмента, `presentationMeta`, дескриптор) не меняются; маршрут дескриптора не проецируется (D3). Продуктовый текст — только через typed-словари и `t`; цвета — только семантические токены, без литералов; font weight ≤500 в feature CSS. Правки живут в ui-subagent (строка каталога), ui-tool (чип карточки), ui-conversation (словари `conversation` NS) и их спеках. Рёбра нарезки: каталог — один тикет (ui-subagent, свои компонентные спеки); карточка — один тикет (ui-tool + словари ui-conversation + расширение фикстуры `subagent-conversation` записанным вызовом с producer-meta, свои компонентные спеки); replay-refresh — отдельный блокирующий тикет после обоих UI-тиклетов (обновляет все затронутые голдены по механическому критерию).

## Ограничения

Механический критерий refresh: whitelist правилом — любой сценарий, захватывающий дерево `Subagent sessions` либо карточку `subagent`/`subagent_fork`; допустимый дифф — строки затронутого ряда каталога (имя `treeitem` и его `text`) и шапки карточки спавна, включая изменённые доступные имена, вызванные строкой маршрута/чипом; любой иной diff блокирует refresh. Положительная часть: обновлённые `tree.expected.md`/`disclosures.expected.md`/`navigation-only.expected.md` обязаны содержать строку маршрута и чип «default» у `agent-1`, а расширенный чип-носитель `subagent-conversation` — чип в шапке карточки; пустой diff там = падение. Названные носители: `snapshots/web/subagent-conversation/{tree,disclosures}.expected.md`, `apps/web/tests/expected/subagent-conversation/navigation-only.expected.md`, `ui.expected.md` сценария (карточка), `apps/web/tests/snapshots/agent-team-panel/task.expected.md` (захватывает дерево); охранники неизменности: `tool-details`, `subagent-summary`, `sidebar-subagent-activity`, `subagent-result-notice` (каталога/карточек с именем не захватывают). Холодное чтение: существующий cold-read-участок `subagent-conversation.e2e.ts` (coldSnapshot + waitForCacheRow + observeSession) расширяется ассертом `modelSelection` в summary-блоке — это носитель вместо субъективной живой пробы; если ассерт падает — стоп и вопрос оператору (host-правка вне рамок v1). Контраст строки маршрута 11px и чипа на фоне меню проверяется пробой в обеих темах и является критерием приёмки; полный маршрут доступен на touch (tap-to-show/aria). Изменение user-perceivable: дизайн-ревью обязательно по правилам клиента, в форке — приёмка оператором; без неё работа не принимается.

## Контекст

Текущее состояние: ряд каталога рисует описание, имя, статус, токены и время ([SubagentHeaderLineage.tsx](../../packages/client/ui-subagent/src/client/SubagentHeaderLineage.tsx)); данные ряда — проекция `subagentCatalog` (`id/mode/label/name`, [catalog.ts](../../packages/subagent/subagent/src/catalog.ts)) плюс summary сессии; маршрута в наборе нет. Селектор модели у адресованного субагента скрыт полностью ([ui-model-selection/index.ts](../../packages/client/ui-model-selection/src/client/index.ts)), поэтому внутри ребёнка маршрут не виден нигде — макет 2 закрывает это отдельным решением позже. Дескриптор continuable-ребёнка несёт резолвнутый маршрут с момента спавна: менеджер снимает `resolveChildAgentOptions` ([manager.ts](../../packages/subagent/subagent/src/manager.ts)), который подмешивает маршрут родителя из его последнего `request/header` ([child-agent.ts](../../packages/subagent/subagent/src/child-agent.ts)); one-shot/fork-дескриптор маршрутных полей не несёт; JSDoc дескриптора («when one was declared») вводит в заблуждение. Projection-канал `modelSelection` фолдит `request/header` + `model/selection` → `{lastUsed, next}` ([model-selection.ts](../../packages/core/agent/src/model-selection.ts)), входит в summary-ключи по умолчанию и доезжает до клиента тем же каналом, что токены; сегодня ни один клиент не читает его из summary (читатели берут face открытой сессии) — cold-ассерт становится первым читателем. Fork-seed копирует префикс родителя включая `request/header` ([fork.ts](../../packages/core/session/src/fork.ts)), fold `modelSelection` не фильтрует унаследованный префикс → маршрут fork-ребёнка непуст с создания. Карточку рисует `DetailsRow` ui-tool: свёрнутая шапка — заголовок + описание, имени в шапке нет (имя — в раскрытых деталях, [control-details-model.ts](../../packages/client/ui-tool/src/client/tool/models/control-details-model.ts)); модель деталей читает `meta.subagentId`, но продюсер выдаёт только `{kind, name}` ([tool-subagent/index.ts](../../packages/subagent/tool-subagent/src/index.ts)) при закрытой output-схеме; `subagent_fork` во всех shipped-пресетах без `modelSelection` ([bundle presets](../../packages/bundle/web-app/presets/standard.patch.yml)). Replay-сценарии: в `subagent-conversation` ребёнок стартует программно (`startActivation`), карточки спавна нет — D1 добавляет записанный вызов; записанные one-shot/grandchild без `request/header` → маршрут только у живого `agent-1`; `tool-details` — легаси-карточка без meta/имени; `subagent-summary` — meta без имени. Прецедент доказательного контура и приёмки оператором — юнит [transcript-readability](transcript-readability.md) (docs/ops/continue.md).

## Демо-путь

Keyless scaffold, расширенный сценарий `subagent-conversation` (D1): открытый каталог показывает строку маршрута с чипом «default» у живого `agent-1`, у записанных one-shot/grandchild строка скрыта (демонстрация скрытого состояния); карточка спавна добавленного вызова показывает чип без раскрытия. Контраст effort двух исполнителей — живая проба на сессии оператора (`executor`, `executor-2`) в обеих темах; узкая ширина и touch — проба scaffold.
