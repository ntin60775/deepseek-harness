# Plugin basics index

Ordered tutorials for a first-time plugin author, from a minimal plugin to an installable bundle.

- [Your first plugin](./index.md) — creates a minimal Harness plugin and loads it into the Web UI.
- [Plugin configuration](./config.md) — defines a `Config` type and schema so a plugin reads settings from cordis.yml.
- [Package and install a plugin](./publish.md) — turns a local plugin into an installable bundle and explains profile layer order.
- [Build a tool](./tool.md) — adds a working tool to the Web UI through a plugin.
