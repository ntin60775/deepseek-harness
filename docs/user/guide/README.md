# User guides index

Task-focused guides for operating DeepSeek Harness; each guide answers one how-to question end to end.

- [Use the Web UI](./index.md) — gets a first-time user from a running server to a first session.
- [Create review Sessions from GitHub webhooks](./github-review.md) — sets up the opt-in overlay that opens a read-only review session when a pull request becomes ready for review.
- [Connect a third-party memory MCP server](./mcp-memory.md) — wires an external memory system into DSH through default-off MCP reference configurations.
- [Run DSH behind a network proxy](./network-proxy.md) — tells users on proxied networks which environment variables DSH reads and which requests stay direct.
- [Plugin indexes](./plugin-market.md) — covers browsing, installing, and publishing indexes of optional bundles.
- [Configure models](./providers.md) — adds DeepSeek keys, other providers, and custom OpenAI-compatible endpoints in Settings.
- [Publish the Web UI behind a reverse proxy](./public-deployments.md) — serves the GUI on a public address through a reverse proxy and `--public-url`.
- [Get started with the Python SDK](./python-sdk.md) — installs the published Python SDK and customizes a DSH profile from your own program.
- [Schedule reminders](./schedule.md) — creates and manages recurring reminders from a conversation or the Automation tasks page.
